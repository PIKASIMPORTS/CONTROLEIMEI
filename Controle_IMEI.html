Instalação no Mac

  1. Descompacte o pacote recebido.
  2. Arraste Controle IMEI.app para a pasta Aplicativos no Finder.
  3. Abra o aplicativo em Aplicativos. Na primeira execução, o macOS pode solicitar autorização de segurança.
  4. Para deixar um atalho permanente no Dock, arraste Controle IMEI.app da pasta Aplicativos para o Dock.
Esta versão abre o sistema no Safari e guarda os dados localmente no navegador. Para proteger seu estoque, exporte backups JSON regularmente.
